# 모아 관리자 대시보드

Next.js App Router, TypeScript, Tailwind CSS, lucide-react, Recharts로 구현한 한국어 관리자 대시보드입니다. **실제 인증 기능이 없는 로컬 데모**이며 DB, 외부 API, 별도 백엔드를 사용하지 않습니다. 역할과 상태는 표시용 데이터입니다.

## 설치 및 실행

Node.js 22.13 이상과 npm이 필요합니다.

```bash
npm ci
npm run dev
```

브라우저에서 http://localhost:3000 을 여세요. 운영 빌드 실행은 다음과 같습니다.

```bash
npm run build
npm start
```

## 화면 및 기능

- `/`: 전체·활성·비활성·이번 달 가입자 요약, 최근 6개월 가입 차트, 최근 가입자 5명. 모두 현재 사용자 데이터에서 계산합니다.
- `/users`: 이름·이메일 검색, 상태 필터, 8명 단위 페이지네이션, 추가·수정 모달, 삭제 확인, 필수값·이메일 형식·중복 검사와 빈 상태 안내.
- `/settings`: 서비스 이름, 라이트·다크 테마, 확인 후 데모 초기화.
- 공통: 반응형 사이드바와 모바일 메뉴, 키보드 포커스 표시, 모달 포커스 제한·복귀 및 Escape 닫기.

## 폴더 구조

```text
src/app/          페이지, 공통 레이아웃, 스타일
src/components/  공통 상태 Provider, 메뉴, 모달, 사용자 폼
src/lib/         데이터 타입, 가상 데이터, 저장·검증·집계 함수
tests/           데이터 로직 테스트
tests/e2e/       Playwright 브라우저 테스트
```

## 저장 및 초기화

React Context로 페이지 사이의 상태를 공유하며 `localStorage`의 `moa-admin:v1` 키에 사용자와 설정을 함께 저장합니다. 첫 실행 또는 초기화 시 실행일 기준 약 6개월에 걸친 가상 사용자 30명을 생성합니다. 월별 집계는 브라우저의 현지 시간대를 기준으로 합니다.

서버와 첫 클라이언트 렌더링은 동일한 로딩 화면을 표시합니다. 브라우저에서 저장값을 읽은 다음 화면을 열며, 기존 데이터나 빈 사용자 목록을 기본값으로 덮어쓰지 않습니다. 손상된 저장값은 자동으로 덮어쓰지 않고 임시 데모와 경고를 표시합니다. 이후 변경 또는 **저장 다시 시도**를 누르면 현재 화면의 데이터로 저장합니다. 저장이 거부되거나 용량이 부족하면 경고를 표시하고 메모리에서 작업을 이어갑니다. 저장 실패 상태의 변경은 새로고침 시 사라질 수 있습니다.

**설정 → 데모 데이터 초기화 → 초기화하기**를 누르면 사용자 30명, 서비스 이름 `모아`, 라이트 테마로 복원됩니다. 또는 개발자 도구에서 위 저장 키를 삭제하고 새로고침하세요. 데이터는 해당 브라우저·주소에만 보관되며 여러 탭의 동시 편집은 동기화하지 않습니다.

## 검증 명령

```bash
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

브라우저 테스트는 운영 빌드가 필요하며 기본적으로 3000번 포트에서 서버를 실행합니다. 포트를 바꾸려면 `PLAYWRIGHT_PORT=3110 npm run test:e2e`를 사용하세요. 사용자 CRUD와 대시보드 연동, 새로고침 저장 유지, 검색·필터·페이지네이션, 설정·초기화, 저장 오류 복구, 모달 키보드 동작과 모바일 메뉴를 검사합니다.

### ASS-5 검증 기록

- 운영 빌드, TypeScript 검사, ESLint 검사, 데이터 로직 테스트 5개 통과.
- Chromium 브라우저 테스트 8개 모두 통과: CRUD와 대시보드 연동, 저장 유지·복구, 설정·초기화, 모달 키보드 동작, 모바일 메뉴·가로 넘침 검사.
- 이 실행 환경에서는 서버 시작 전 연결 확인이 대기할 수 있어, `npm run start -- --hostname 127.0.0.1 --port 3110`으로 서버를 먼저 시작한 뒤 `PLAYWRIGHT_PORT=3110 npm run test:e2e -- --workers=2`로 검증했습니다.
- `package-lock.json`을 추가했고 별도 작업 디렉터리에서 깨끗한 설치를 검증했습니다. 이 로컬 환경의 npm 12에서는 선택적 레지스트리 tarball 때문에 `npm ci --allow-remote=all`이 필요했습니다. 일반 CI는 Node 24의 npm으로 `npm ci`를 사용합니다.
- Next.js와 eslint-config-next는 16.3.6으로 업데이트했으며 npm audit 결과 취약점 0건입니다.
- GitHub Actions에서 lint, 타입 검사, 단위 테스트, 빌드, Chromium E2E를 수행합니다.
